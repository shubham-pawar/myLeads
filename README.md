# myLeads

**myLeads** is a Chrome extension that lets you save and manage important links with just one click. It is a lightweight and useful productivity tool for storing leads, resources, or any webpage you want to revisit later.

## Features
- Save current tab URLs instantly
- Manually add custom links
- View all saved leads in one place
- Delete all saved links when needed
- Simple and clean Chrome extension interface

## How It Works
1. Open the Chrome extension.
2. Click **Save Tab** to store the current page URL.
3. Or enter a URL manually and save it.
4. Access your saved links anytime from the extension pop-up.

## Tech Stack
- JavaScript
- HTML
- CSS
- Chrome Extensions API

## Installation
1. Clone this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the project folder.

## Usage
- Click the extension icon in Chrome.
- Save your current tab or add a custom link.
- Click any saved link to open it in a new tab.
